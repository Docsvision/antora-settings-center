= Типы карточек для документов

Чтобы настроить типы карточек для документов, разрешённые для добавления в карточку _Группа заданий_ при помощи элемента управления "xref:backoffice:desdirs:layouts/std-ctrl/references.adoc[Ссылки]":

. xref:select-type.adoc[Выберите] базовый тип карточки _Группа заданий_.
. Выберите в _Дереве видов карточек_ дочерний вид.
. Перейдите в раздел _Группа заданий_.
. В поле _Тип карточек для документов_ установите флаги напротив тех типов карточек _Документ_, которые можно будет добавлять в карточку _Группа заданий_.
+
[NOTE]
====
Выбор типов может быть ограничен, см. "xref:general-hide-kind.adoc[Недоступность вида для выбора]".
====
