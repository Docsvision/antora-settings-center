= Дерево видов карточек

Дерево видов карточек расположено в левой части карточки справочника.

.Дерево видов карточек
image::kind-tree.png[Дерево видов карточек]

Дерево содержит список доступных видов карточек.

.Дерево состоит из трёх элементов:
* <<type,Раскрывающийся список>> для выбора типа карточки.
* <<filter,Фильтр>> -- поле для фильтрации всего дерева по названию.

// Виды, для которых настроено xref:general-forbid-card.adoc[ограничение на создание карточек], отображаются серым курсивом. Виды, для которых настроено xref:general-hide-kind.adoc[ограничение на выбор вида], отображаются серым шрифтом.

Если пользователь начал изменять настройки вида, изменение настроек для других пользователей блокируется. Об этом будет сказано справа, напротив заголовка вида:

.Вид заблокирован для изменений
image::blocked-by-you.png[Вид заблокирован для изменений]

Если вид заблокирован текущим пользователем, сообщение будет содержать подпись `Заблокировано вами`. Если инициатор блокировки -- другой пользователь, в сообщении будет указано его имя.

Настройки заблокированного для изменений вида карточек изменять запрещено. Блокировка может быть снята другим пользователем, при этом вид будет заблокирован для изменений у изначального пользователя

[#type]
== Выбор типов карточек

Работа с _Конструктором карточек_ начинается с выбора типа карточки в выпадающем списке типов карточек.

[WARNING]
====
Возможность полноценно работать с видами имеется только при наличии лицензии на модуль _Конструктор карточек_. При отсутствии этой лицензии у пользователя будет возможность менять часть существующих настроек, однако создавать, удалять и переименовывать виды при этом нельзя. Также без лицензии нельзя менять настройки наследования параметров для вида.
====

[NOTE]
====
Чтобы с карточками пользовательских библиотек можно было корректно работать в _Конструкторе карточек_ и _Конструкторе состояний_, эти карточки должны иметь секцию `System` с полями `State` и `Kind`.
====

.Чтобы выбрать тип карточки:
. Откройте главное окно _Конструктора карточек_.
. Нажмите на поле с названием _Тип карточки_ и стрелкой в правой части.
+
Будет раскрыт список доступных типов карточек, зарегистрированных в базе данных библиотек карточек. Типы карточек отсортированы в алфавитном порядке.
+
.Список доступных типов карточек
image::types-list.png[Список доступных типов карточек]
+
. Выберите требуемый тип карточки.
+
.По умолчанию в поле будут доступны следующие типы:
* "xref:select-type.adoc#task-group-type[Группа заданий]".
* "xref:select-type.adoc#document-type[Документ]".
* "xref:select-type.adoc#task-type[Задание]".
* "xref:select-type.adoc#department-type[Карточка подразделения]".
* "xref:select-type.adoc#partner-department-type[Карточка подразделения контрагента]".
* "xref:select-type.adoc#server-card-type[Карточка сервера]".
* "xref:select-type.adoc#employee-card-type[Карточка сотрудника]".
* "xref:select-type.adoc#partner-employee-card-type[Карточка сотрудника контрагента]".
* "xref:select-type.adoc#directory-line-card-type[Карточка строки справочника]".
* "xref:select-type.adoc#approval-type[Согласование]".
* "xref:select-type.adoc#approval-stage[Этап согласования]".
+
Выбранный тип будет отображен в _Дереве видов карточек_.
+
.Пример отображения базового типа "Группа заданий" в окне справочника
image::task-group-type.png[Пример отображения базового типа "Группа заданий" в окне справочника]

[#filter]
== Фильтрация видов по названию

Пользователь может найти нужный тип в поле _Фильтр_, начав вводить текст в поисковой строке. Совпадения подсвечиваются цветом во всех строках списка.

Чтобы выбрать нужное значение, выберите его нажатием левой кнопки.

[#context]
== Контекстное меню конструктора

Для _Конструктора карточек_ доступно контекстное меню, которое вызывается нажатием правой кнопки на дереве видов карточек.

.Контекстное меню конструктора карточек
image::context-menu-commands.png[Контекстное меню конструктора карточек]

.Контекстное меню содержит следующие команды:
[cols="20,80",options="header]
|===
|Команда |Назначение

|Добавить вид
|Создаёт новый вид для текущего типа карточки, добавляя его в качестве дочернего вида к выбранному в xref:kind-tree.adoc[Дереве видов карточек].

|Переименовать вид
|Позволяет переименовать выбранный вид карточки.

Кнопка недоступна для корневого вида (типа карточки).

|Удалить вид
|Удаляет выбранный в дереве вид карточки.

Команда недоступна для корневого вида (типа карточки). Следует учитывать, что при удалении вида может нарушиться корректная работа ранее созданных карточек (соответствующего вида).

Вместо удаления можно использовать флаг `*Сделать вид недоступным для выбора*`.

// |Настроить расширения
// |Отображает диалог xref:kind-extensions.adoc[настройки] расширений параметров типа карточек.

|Копировать вид
|Копирует выбранный в дереве вид в буфер обмена. Для вставки используется команда *Вставить вид*. Скопировать можно только вид, содержащий свои собственные настройки.

Если вид наследует настройки от родительского, то он не может быть скопирован.

|Вставить вид
|Добавляет копию вида карточки из буфера обмена в качестве дочернего вида к выбранному в дереве.

|===
