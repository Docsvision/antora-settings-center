= Конструктор карточек

_Конструктор карточек_ предназначен для управления иерархией видов существующих типов карточек, добавления и удаления видов, а также настройки определённых параметров видов.

Для работы со справочником требуется лицензия.

[NOTE]
====
В _Конструкторе карточек_ можно выбирать типы карточек из любых библиотек, однако корректная работа поддерживается только с типами карточек библиотеки _{bo}_.
====
