= Область настроек вида

_Область настроек вида_ позволяет изменять параметры карточек выбранного в дереве вида. Параметры сгруппированы по разделам. Набор разделов зависит от текущего типа карточки.

.Область настроек вида
image::kind-settings-area.png[Область настроек вида]

[#general-tab]
== Раздел "Общие"

Раздел _Общие_ доступен для каждого вида. В разделе можно изменить определённые настройки вида, характерные для любого типа карточки.

.Общие настройки вида
image::general-kind-settings.png[Общие настройки вида]

Флаг `*Запретить создание карточек данного вида*` позволяет xref:general-forbid-card.adoc[запретить] создание карточек определённых видов.

Флаг `*Сделать вид недоступным для выбора*` позволяет xref:general-hide-kind.adoc[скрыть] вид при выборе карточки данного вида.

Область _Наследование_ позволяет xref:general-inherit.adoc[настроить наследование] параметров родительского вида для дочернего вида.

Область _Процессы_ позволяет xref:general-business-process.adoc[связать] вид карточки с бизнес-процессами.

В области _Режимы создания_ можно настроить xref:card-create-mode.adoc[способ создания] карточки: размещение, вид родительской карточки, шаблон карточки для создаваемой карточки, тип ссылки, связывающей создаваемую карточку текущего вида с родительской.

[#documents-tab]
=== Раздел "Документы"

В разделе добавляются файлы к карточке и настраиваются принципы загрузки и условия отображения приложенных файлов.

.Раздел "Документы"
image::docs-tab.png[Раздел "Документы"]

.Раздел включает следующие области:
* Область _Поведение_ содержит настройки для управления xref:document/doc-versions.adoc[версиями] (_Тип версионирования_) и способом xref:document/main-file-source.adoc[загрузки] файлов (_Источник загрузки основных файлов_).
* Переключатель `*Запретить предпросмотр*` позволяет исключить возможность предварительного просмотра файлов.
* Переключатели в области _Режим отображения основных файлов_ и _Режим отображения дополнительных файлов_ позволяют настроить способы представления списков файлов.
* Флаг `*Сортировать по названию*` включает сортировку файлов по названию. По умолчанию файлы отображаются без сортировки.
* Область _Категории_ содержит поле настройки для управления корневой xref:document/root-category.adoc[категорией] карточки.
* Область _Файлы_ позволяет xref:document/file-from-system.adoc[добавлять], редактировать и xref:document/delete-attached-files.adoc[удалять] файлы в карточке документа.

.Раздел "Экспорт"
image::export-tab-doc.png[Раздел "Экспорт"]

[#properties-doc]
=== Раздел "Свойства"

Раздел _Свойства_ предназначен для настройки синхронизации свойств файла Microsoft Office версий 2016x86 и младше (`.docx`, `.xlsx`, `.pptx` и другие) документа с полями карточки. Если соответствующие свойства документа заполнены, они будут подставлены в одноименные поля раздела _Свойства_ карточки документа.

.Раздел "Свойства"
image::properties-tab-doc.png[Раздел "Свойства"]

[#signature-doc]
=== Раздел "Подпись"

В разделе _Подпись_ xref:document/signature-settings.adoc[настраиваются] параметры электронной подписи.

.Раздел "Подпись"
image::signature-tab-doc.png[Раздел "Подпись"]

.Раздел "Подпись" включает следующие области:
* Область _Подписание документа_, предназначенную для настройки способа подписания файлов документа.
* Область _Атрибуты, включаемые в подпись_, предназначенную для добавления в подпись определённых атрибутов.
* Область _Доступные метки_, предназначенную для выбора из _Справочника меток подписей_ меток, которые могут использоваться для пользовательского вида карточки _Документ_.
* Область _Подписание операций_, предназначенную для настройки вида подписи для совершаемых с карточкой операций.

[#unique-doc]
=== Раздел Проверка уникальности

В разделе _Проверка уникальности_ xref:document/unique-attributes-check.adoc[настраиваются] атрибуты карточек, которые необходимо проверять на уникальность.

.Раздел "Проверка уникальности"
image::unique-tab-doc.png[Раздел "Проверка уникальности"]

.Раздел включает следующие области:
* Область _Атрибуты документа, проверяемые на уникальность_, предназначенную для добавления и удаления полей, которые требуется проверять.
* Поле _Объединение_, позволяющую определить способ поиска карточек.

=== Раздел "Задание"

Раздел предназначен для настройки основных параметров карточки Задания.

.Раздел "Задание"
image::task-tab.png[Раздел "Задание"]
