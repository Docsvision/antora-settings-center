= Переименовать вид

Переименование доступно только для дочерних видов. Для базовых типов карточек изменение названий запрещено. Также запрещено изменять названия видов, заблокированных другими пользователями.

.Чтобы изменить название вида:
. Выберите в _Дереве видов карточек_ вид, который требуется переименовать.
. Вызовите контекстное меню и выполните команду *Переименовать вид*.
. В строке редактирования названия введите новое название для вида.
. Нажмите kbd:[Enter].
