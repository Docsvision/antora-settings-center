= Стартовая страница {of-sc}

{sc} работает на базе {wc}а {dv}, поэтому чтобы открыть {sc}, укажите в адресной строке браузера url вида: `\http://адрес-{wc}а/#/appbuilder`. При переходе по адресу будет открыта главная страница {of-sc}. На рисунке ниже представлен общий вид пользовательского интерфейса {of-sc}.

.Пользовательский интерфейс {of-sc}, главная страница
image::gui.png[Пользовательский интерфейс {of-sc}, главная страница]

.Пользовательский интерфейс включает:
. *Рабочую область*, в которой выполняются пользовательские задачи (настройка конфигурации, просмотр метрик и пр.).
+
При запуске {of-sc} в рабочей области будет открыта домашняя страница с набором плиток созданных приложений. Расположение плиток можно менять перетаскиванием.
. Наверху располагается панель со следующими элементами:
+
* Логотип {of-sc} -- image:buttons/logo.png[Домик]. Вне зависимости от текущего нахождения нажатие на логотип переводит на главную страницу.
* Кнопка image:buttons/language.png[Флаг страны], которая переключает язык пользовательского интерфейса.

[#new-app]
== Создание нового приложения

Создание приложения выполняется с главной страницы.

.Чтобы создать новое приложение:
. Нажатие кнопки image:buttons/new-app.png[Плюс синий] откроет окно создания нового приложения. Кнопка всегда отображается на главной странице, а также при просмотре приложения.
.  Заполните информацию о приложении:
+
* Название -- обязательное поле, в котором необходимо указать отображаемое имя приложения.
* Описание -- необязательное поле, в котором можно указать дополнительные сведения, необходимые для идентификации приложения. Поле отображается при просмотре плитки приложения (при нажатии).
+
. После нажатия кнопки *Создать* на стартовую страницу будет добавлена новая плитка настроек приложения.
+
При этом создается также сама карточка настроек приложения. В карточке будет указана _Дата_ создания, _Автор_, создавший карточку, а также _Название_ и _Описание_, указанные в соответствующих полях при создании.
