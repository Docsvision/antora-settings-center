= Общие сведения о модуле

{appd} -- самостоятельное приложение для настройки и публикации в различные БД {dv} настроенных приложений. {appd} включает несколько дизайнеров:
+
* *Дизайнер процессов* -- компонент для графической настройки процесса в BPMN.
* *Дизайнер форм* -- компонент для настройки разметок карточки.
* *Дизайнер ролей* -- компонент для настройки ролей приложения.
* *Дизайнер папок* -- компонент для настройки папок, поисков и представлений.

// Целевая БД -- база данных, куда выполняется публикация приложения.
// +
// . БД разработки -- База данных DV, с которой Конструктор приложений работает по умолчанию. При настройке приложений, где используются сущности DV (группы СС, конструктор справочников и т.п.), в конструкторе приложений выбираются значения из этой БД. БД разработки обслуживается *Интегрированным ВК* (см.п.8)
// . Интегрированный {wc} -- {wc} {dv}, компоненты которого будет использовать {appd} для отображения ЭУ. БД по умолчанию этого {wc}а будет использоваться в как *БД Разработки* (см.п.5) UPD 16/07/26 -- КП работает с единственным ВК, к которому подключен Центр настройки
